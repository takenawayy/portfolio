Hi! I'm Isal, an Exhibition Designer based in New Delhi, India. I build compelling, functionally efficient displays through content-focused design, clever material selection, minimal graphics, and the use of digital tools and simulations where necessary.

Some of my key past projects include a levitating dragon installation built using only tyre tubes (no joineries), creating a game environment and player mechanics for a two-player VR game called SpaceCoop, and designing a solar pipe sundial using a solar-path analysis for a museum project- among others.

I also work in product design! Some of my finished projects include a task light designed for visual ergonomics, and an experimental 3d-printed running shoe with springs blades (not practical). I have also recently started programming light web apps using Python and HTML.

Outside of work, I enjoy travelling in the city, reading, playing football and thinking about irrationality.
